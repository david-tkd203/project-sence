Evaluación Módulo #6: Primeros Pasos con Node y Express

Estructura base, rutas modulares, contenido estático y persistencia plana en archivo.

🚀 Servidor Iniciado y Operativo

Esta página HTML estática es servida directamente desde la carpeta pública mediante el middleware express.static('public').

Rutas Disponibles:

  • GET /: Vista de inicio HTML (Página actual).
  • GET /status: Endpoint público que retorna el estado del servidor en formato JSON.
    Probar /status (JSON)

📁 Arquitectura Modular

Estructurado en 5 carpetas: routes/, controllers/, middlewares/, public/ y logs/.

📝 Persistencia Plana

Cada visita a las rutas se registra automáticamente en logs/log.txt usando fs.appendFile.

⚙️ Variables de Entorno

Configuración dinámica del puerto mediante dotenv y .env.
